# WFS PROJECT v2.5.0 — Secure Spatial Studio (Local RC)

Windows 10/11 + Docker Desktop local AI Software House, upgraded from v2.4. Keeps all thirteen menus, ten divisions, Master Orchestrator, three-floor 3D studio, RBAC, project privacy, operator QA/GitHub approval, full-stack preview requests, queue, task recovery and FinOps.

## Quick start (Windows)

1. Extract this ZIP into its own folder. On upgrade, **stop v2.4 and back up its `.env` and `data/`** first. Copy those two only into this new installation; never replace v2.5 source files with v2.4.
2. Start Docker Desktop (Linux containers / WSL2). Run `START_WFS_PROJECT.cmd` or `powershell -ExecutionPolicy Bypass -File scripts/start-windows.ps1 -WorkerReplicas 3`.
3. Open `http://127.0.0.1:8080`. On first start, bootstrap creates the owner password and `.env`. The site is local-only by default; do not publish to the internet without HTTPS and an external security review.
4. Enable AI only by setting your own valid provider key in `.env` and restarting; provider costs are separate. Demo mode is always explicitly labeled and is not real agent output.

## New v2.5 MFA / account security

Open **Team & Access → Authenticator MFA**, enter your own password, copy the displayed Base32 secret into a TOTP authenticator (Google Authenticator / Microsoft Authenticator or any RFC6238 client), verify a six-digit code, and **save all eight one-time recovery codes offline**. MFA is optional per user and requires an authenticator/recovery code at the next login. Enabling MFA revokes other browser sessions; disabling requires password + code and revokes all sessions. Five invalid codes in five minutes trigger a durable account MFA cooldown.

**Important:** The MFA secret is encrypted in SQLite using a key derived from the installed `WFS_SESSION_SECRET` in `.env`; keep encrypted backups of BOTH `.env` and `data/`, and never rotate that key without planning migration/reset. If both authenticator and recovery codes are lost, an authorized local operator may stop the services and run `python scripts/reset-mfa-local.py --username admin` after backing up data. That offline reset is not exposed to the web.

## Spatial & GPU

The office reuses the eight project-created GLB assets with a 3D building overview and three floors. Multi-avatar occupancy now follows the count of authenticated, currently active agent runs, up to three visible avatars per room. No idle desk is depicted as live work. Run the CPU 3D renderer on low-end devices or switch to the 2.5D fallback. On real Windows GPUs, run `scripts/acceptance_v25_windows.py` to capture browser evidence. GPU timer queries are optional and not equivalent to display FPS or VRAM.
