# WFS Accessible Product Experience

For any visual UI, maintain a complete HTML equivalent of canvas content, accessible keyboard actions for selecting rooms, rotate/zoom/reset controls, logical focus order, visible focus styles, and no motion-only statuses. Respect `prefers-reduced-motion` and a user pause control. Announce important status updates sparingly, not on every frame. Test 200% browser zoom, high-contrast and mobile. Explicitly report screen-reader testing that is not completed. Follow current WCAG recommendations without claiming certification from smoke tests alone.
